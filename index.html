🖥️ Propuesta de Arquitectura de Red y Conexión entre Estaciones (Req. 17)

Para interconectar las computadoras de trabajo operadas en cada estación con la base de datos central en Oracle XE, se propone la siguiente arquitectura estándar y segura:

  • Red Privada Virtual (VPN IPSec / WireGuard): Cada PC de estación se conecta de forma cifrada a la red de la Municipalidad de Guatemala.
  • Arquitectura Cliente-Servidor REST API (Node.js): Las PCs ejecutan este cliente web interactuando mediante peticiones JSON seguras (HTTPS).
  • Mapeo de Fallo Off-line: En caso de pérdida temporal de conectividad en una estación, el navegador guarda en almacenamiento local (`LocalStorage`) el registro del operador y sincroniza con Oracle al restablecer el enlace.
